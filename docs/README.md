# Jerry Lee 個人品牌網站

這是多頁式 Personal Portfolio，不是一頁式網站。

## 檔案結構

- index.html：首頁
- about.html：關於我
- skills.html：技能
- projects.html：專案
- timeline.html：時間軸
- research.html：研究方向
- achievements.html：成就
- contact.html：聯絡
- assets/css/style.css：網站樣式
- assets/js/main.js：動畫與互動效果

## GitHub Pages 使用方式

1. 把整個資料夾內容上傳到 GitHub repository。
2. 確認根目錄有 index.html。
3. 到 Settings → Pages 開啟 GitHub Pages。
4. 如果要讓「下載履歷」按鈕有效，請放入 resume.pdf。
5. 請把 GitHub、LinkedIn、HackMD 連結換成自己的正式網址。
